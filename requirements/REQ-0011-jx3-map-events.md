# REQ-0011：剑网 3 地图事件查询

## 基本信息

- 状态：待验收
- 创建日期：2026-07-31
- 最后更新：2026-07-31
- 负责人：待定

## 背景

当前宠物快捷面板已经支持公告、技改、开服状态和日历，但不能查看地图公共事件的近期排期。用户需要进入游戏或其他工具，才能确认楚天社、云从社和披风会接下来会出现什么事件、位于哪张地图及什么地点。

JX3API 提供 `GET https://www.jx3api.com/active/celebs` 地图事件接口，可查询指定组织接下来的 `10` 条排期。该接口可以作为首版第三方运行时数据源。

## 目标

- 用户可以从宠物快捷面板快速进入地图事件页面。
- 用户可以分别查看楚天社、云从社和披风会接下来的事件排期。
- 页面清楚展示事件时间、地图、地点、阶段名称和事件说明。
- 数据获取失败时不影响宠物、公告、技改、开服状态和日历功能。

## 范围

### 包含

- 在现有宠物快捷面板增加“地图事件”入口。
- 在当前辅助窗口内进入地图事件二级页面，不创建新的 Tauri 窗口。
- 支持楚天社、云从社和披风会三个分类切换。
- 使用 JX3API `active/celebs` 接口查询所选分类接下来的 `10` 条排期。
- 展示接口返回的 `time`、`map`、`site`、`stage` 和 `desc`。
- 显示第三方数据来源、刷新状态、最后更新时间、空数据和错误状态。
- 提供手动刷新、短时缓存和并发请求互斥。

### 不包含

- 不接入 JX3API 付费 Token。
- 不依赖推栏 Ticket、Cookie 或账号登录。
- 不在首版后台轮询地图事件。
- 不在首版提供宠物气泡、系统通知或事件开始提醒。
- 不提供游戏内自动寻路、地图坐标定位或客户端联动。
- 不提供历史事件查询、完整时间表或用户自定义事件。
- 不把 JX3API 第三方数据标记为西山居官方数据。

## 数据源调研

### 接口

```text
GET https://www.jx3api.com/active/celebs?name=<事件名称>
```

### 接口属性

- JX3API OpenAPI 名称：地图活动。
- 描述：楚天社 / 云从社 / 披风会接下来 `10` 条排期。
- 等级：`LV.0`，当前无 Token 可以调用。
- `name` 为必填参数；缺少时返回 `code=400` 和“参数 [name] 不能为空”。
- 2026-07-31 无 Token 实测楚天社、云从社、披风会均返回 `code=200`。

### 支持的查询值

- `楚天社`
- `云从社`
- `披风会`

### 返回字段

| 字段 | 用途 |
| --- | --- |
| `time` | 事件预计发生时间，当前格式为 `HH:mm` |
| `map` | 所在地图 |
| `site` | 地图内地点 |
| `stage` | 事件或阶段名称 |
| `desc` | 事件说明 |
| `icon` | 上游图标编号；首版不展示 |

### 来源

- `https://www.jx3api.com/openapi`
- `https://www.jx3api.com/active/celebs`

## 需求说明

### 1. 入口与导航

1. 用户点击黄鸡打开现有快捷面板。
2. 用户点击“地图事件”入口。
3. 应用在当前辅助窗口内进入地图事件二级页面。
4. 页面提供返回快捷面板和关闭辅助窗口操作。

### 2. 分类切换

- 页面提供楚天社、云从社和披风会三个切换入口。
- 用户没有历史选择时默认打开楚天社；成功切换后记住上次选择，下次进入优先恢复。
- 每次只请求当前选中的分类，不在首次打开时并发请求全部三个分类。
- 已成功请求的分类可以使用独立缓存，切换回来时优先展示缓存。
- 切换分类时不得展示上一分类的数据冒充加载结果。

### 3. 事件列表

- 按上游返回顺序展示接下来的 `10` 条排期。
- 每条事件突出显示时间和阶段名称。
- 地图与地点作为位置组合展示。
- 说明文本在卡片内完整换行展示，不执行远程 HTML。
- 首版使用本地固定分类标记，不请求或展示上游 `icon` 对应的远程图标资源。
- 同一分类、时间、地图、阶段和地点完全相同的重复记录合并。
- 列表在页面内部滚动，不扩大辅助窗口透明点击区域。

### 4. 刷新与缓存

- 首次进入且没有缓存时立即请求当前分类。
- 缓存按分类隔离。
- 每个分类成功数据缓存 `60` 秒。
- 页面提供手动刷新。
- 同一分类连续手动刷新至少间隔 `60` 秒。
- 同一分类同时只允许一个请求。
- 请求失败不得覆盖已有成功缓存。
- 有缓存但刷新失败时继续展示缓存并提示刷新失败。
- 不在后台轮询，不主动弹出气泡提醒。

### 5. 时间处理

- `time` 当前只有 `HH:mm`，没有明确日期和时区。
- 页面首版只将其标记为“时间”，在确认跨日规则前不推导具体日期或倒计时。
- 数据更新时间使用 JX3API 顶层 Unix 时间戳或本地成功获取时间，并按 `Asia/Shanghai` 展示。

### 6. 状态与错误

- 区分首次加载、刷新中、成功、合法空数据、缓存数据和请求失败。
- 参数由应用内固定枚举生成，不接受任意用户输入。
- 上游返回未知字段或单条记录字段缺失时，跳过无法识别的记录或使用安全占位，不导致页面崩溃。
- 地图事件错误不得影响其他快捷面板功能。

## 实施记录

- 新增独立 Rust `jx3_map_events` 适配器，只接受楚天社、云从社和披风会三个固定分类，并通过 JX3API `active/celebs` 获取排期。
- 新增按分类隔离的持久化缓存 `jx3-map-events-cache.json`，缓存有效期和连续手动刷新冷却均为 `60` 秒；请求失败不覆盖已有成功缓存。
- 数据层规范化时间、地图、地点、阶段和说明字段，按分类、时间、地图、地点和阶段去重，最多保留上游前 `10` 条记录。
- 新增 `get_cached_jx3_map_events` 和 `fetch_jx3_map_events` Tauri 命令，不读取 Token、Cookie、Ticket 或账号信息。
- 快捷面板新增“地图事件”入口，并在当前辅助窗口内打开独立 Vue 二级页面。
- 页面支持三个分类按需切换、首次默认楚天社、使用 `localStorage` 记住上次选择、缓存优先加载、手动刷新、完整说明换行、错误降级和列表内部滚动。
- 页面使用本地“楚 / 云 / 披”分类标记，不加载 JX3API `icon` 资源；首版没有后台轮询、气泡或系统提醒。
- 快捷面板的剑网 3 入口采用上排三个、下排两个的均衡布局，保持“地图事件”等较长名称横向展示；同步增加首页面板高度，避免新增一行入口后内容拥挤。
